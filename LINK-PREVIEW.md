## ?? Preview Lokal (Jika Download)

### Cara 1: Double Click
```bash
1. Download/Clone repository
2. Buka folder workspace
3. Double-click index.html
4. Website akan buka di browser
```

### Cara 2: Python Server
```bash
# Buka terminal di folder workspace
python -m http.server 8000

# Buka browser, visit:
http://localhost:8000
```

### Cara 3: Node.js
```bash
# Install serve
npm install -g serve

# Run server
serve

# Buka:
http://localhost:3000
```

## ?? Troubleshooting

### Preview Tidak Muncul?
```
1. Check internet connection
2. Clear browser cache (Ctrl+Shift+R)
3. Try different browser
4. Use local preview (double-click index.html)
```

### API Tidak Load?
```
1. Open browser console (F12)
2. Check for CORS errors
3. Try test-api.html first
4. Consider deploy to Netlify (fixes CORS)
```

### Mobile Preview?
```
1. Deploy ke Netlify (fastest)
2. Get link: https://your-app.netlify.app
3. Open di HP
```
