## ?? Troubleshooting

### Preview Tidak Muncul?
**Solusi:**
1. Clear browser cache (Ctrl+Shift+R)
2. Try different browser
3. Download file dan buka lokal
4. Deploy ke Netlify

### Styling Aneh/Broken?
**Pasti penyebabnya:**
- Pakai file yang salah (index.html tidak jalan online)
- **SOLUTION**: Pakai `preview-all-in-one.html`!

### API Tidak Load?
**Normal!** HTMLPreview kadang block API calls.
**Solution:**
- Deploy ke Netlify (fix CORS)
- Atau test lokal
