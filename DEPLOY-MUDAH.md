# 🌐 CARA DEPLOY WEBSITE KE INTERNET (GRATIS!)

## OPSI 1: NETLIFY DROP (PALING MUDAH!)

### Dari Komputer/Laptop:

1. Buka: https://app.netlify.com/drop
2. Drag seluruh folder /workspace ke area drop
3. Tunggu 30 detik
4. DAPAT LINK! (contoh: https://instrategic-xyz.netlify.app)
5. Buka link dari HP!

---

## OPSI 2: GITHUB PAGES

1. Upload semua file ke GitHub repository
2. Setting → Pages → Enable
3. Dapat link: https://username.github.io/instrategic

---

## OPSI 3: VERCEL

1. Buka: https://vercel.com
2. Import project
3. Deploy
4. Dapat link langsung!

---

Link akan aktif 24/7 dan bisa dibuka dari HP kapan saja!
