```bash

```
1. Install extension "Live Server"
2. Klik kanan index.html
3. Pilih "Open with Live Server"

## ?? Tips Penggunaan

### Untuk Developer:
1. Gunakan VS Code + Live Server
2. Buka DevTools untuk inspect
3. Test di berbagai browser & device
4. Customize warna di CSS Variables

### Untuk Designer:
1. Semua warna ada di `:root` CSS
2. Spacing menggunakan 8px grid
3. Border radius konsisten
4. Icons dari SVG inline

### Untuk User:
1. Tekan `Ctrl/Cmd + K` untuk quick search
2. Hover untuk lihat efek glow
3. Klik stock card untuk detail
4. Test di mobile untuk responsive
